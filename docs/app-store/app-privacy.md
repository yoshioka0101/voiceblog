# App Store Connect「App のプライバシー」回答メモ

v0.0.1 時点の実装に合わせた回答。送信内容を変えたら見直すこと。

## データの収集

「はい、このアプリからデータを収集します」を選ぶ。

| データの種類 | 該当項目 | 用途 | ユーザーにリンク | トラッキング |
|---|---|---|---|---|
| ユーザコンテンツ | その他のユーザコンテンツ（文字起こし・記事・プロンプト） | App の機能 | はい | いいえ |
| ID | ユーザ ID（端末で生成した識別用の値） | App の機能 | はい | いいえ |
| その他のデータ | その他のデータタイプ（はてなブログ・Qiita のアクセストークン、投稿履歴） | App の機能 | はい | いいえ |

「ユーザにリンク」を「はい」にする理由: 匿名でも、端末ごとの識別用の値でデータをまとめて保存しているため。

## 収集しないもの

- 連絡先情報（氏名・メール・電話番号）: ログインがないため取得しない
- オーディオデータ: 録音はサーバーに送らない。文字起こしは Apple の音声認識で行う（Apple 側の処理は開発者の収集に当たらない）
- 位置情報、連絡先、閲覧履歴、使用状況データ、診断: 取得していない

## トラッキング

なし。ATT（App Tracking Transparency）の許可ダイアログも不要。

## 公開前に確認すること

- [ ] Gemini API キーが有料プラン（Paid tier）か確認する。無料枠だと送信内容が Google のサービス改善に使われることがあり、プライバシーポリシーの記載と食い違う
- [ ] 診断やクラッシュレポートの SDK を入れたら「診断」を追加する
- [ ] 監視（OpenTelemetry など）で利用者の内容をログに残さないことを確認する
